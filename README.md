# vibzbar

Website for **VIBZ**, a luxury mobile bartending service serving the greater Sacramento area. VIBZ brings craft cocktails and a polished bar experience to weddings, private events, and corporate gatherings.

🌐 [vibzbar.com](https://vibzbar.com)
📸 Instagram: [@vibzbar](https://instagram.com/vibzbar)
